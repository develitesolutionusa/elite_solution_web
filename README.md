# Elite Solutions USA

Marketing site for Elite Solutions USA — financial and non-financial business services.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4 + brand design tokens from the original preview
- `next/font` (Bricolage Grotesque + Figtree)

## Pages

- `/` — Home
- `/services` — Services
- `/portfolio` — Portfolio
- `/about` — About
- `/contact` — Contact (mailto form)

## Develop

```bash
npm run dev
npm run build
npm start
```
